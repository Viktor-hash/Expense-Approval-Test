# Expense-Approval-Test

This project implements an expense approval system with customizable approval flows. It includes a service for managing expense approvals and a test suite to validate its functionality.

---

## **Features**
- Multi-step approval flow based on user hierarchy.
- Customizable approval thresholds.
- Unit tests using Mocha and Chai.

---

## **Prerequisites**
Before running the project, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (version 14 or higher)
- [npm](https://www.npmjs.com/) (comes with Node.js)

---

## **Setup Instructions**

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd Tiplalti-Expense-Approval-Test
   ```

2. **Install Dependencies**: Install the required Node.js dependencies:
   ```bash
    npm install
   ```

3. **Run the Project**: To execute the example usage in approvalService.js, run:
   ```bash
    node approvalService.js
   ```

4. **Run Tests**: To run the test suite and validate the functionality, use:
   ```bash
    npm test
   ```
